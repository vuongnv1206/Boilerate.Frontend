# Theme và shared presentation — 20/10/2026

## Đã triển khai

- `src/styles/tokens/_index.scss` là nguồn giá trị màu của workspace. CSS variables cho palette và semantic roles được PrimeNG preset dùng lại ở cả hai color schemes; overlay gắn vào `body` lấy cùng root variables.
- Đưa dropdown width, option density, checkbox sizes và tabs vào component tokens được preset Aura đang cài hỗ trợ. Giữ global adapter cho các ngoại lệ compact, separator, font và focus hiện có.
- Tách reset/typography/utilities sang `styles/base/_index.scss`, native buttons và field presentation sang `styles/base/_controls.scss`. Root stylesheet chỉ lắp ghép các lớp.
- Thêm `FieldMessage`, `StatusBadge`, `ContentState`. List/editor/gallery dùng chung thông báo trường và trạng thái; ý nghĩa published/draft/archived được feature chuyển sang tone trình bày, không nằm trong global styles.
- ContentState hỗ trợ empty/loading/error, giữ action do màn hình cung cấp, không gọi API hoặc đổi focus. List dùng trạng thái không có kết quả; editor dùng trạng thái không tìm thấy bản ghi; gallery có bộ thử ba trạng thái trong tab Phản hồi.
- Giữ animation bình thường, CSS fallback theo hệ điều hành, prepaint theme và hành vi dialog/drawer hiện có. Chưa rút các dialog có guard/focus riêng thành wrapper chung.
