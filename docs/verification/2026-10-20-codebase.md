## Tái chạy

Chạy `npm run check`. Để test snapshot cùng trạng thái license với CI, build bằng `PRIMEUI_LICENSE_KEY` rỗng và `API_BASE_URL=/api`, rồi `npm run test:e2e`; `.env.local` vẫn được giữ. Chromium cài bằng `npx playwright install chromium`. Test server chỉ bind loopback 4300. Raw report/trace ở `artifacts/playwright-report/` và `artifacts/playwright-results/`, không commit.

Ảnh so sánh nằm trong `artifacts/comparison/{before,after}`. Baseline trước refactor có thể dựng lại từ Git `111e7fe`; việc chụp giữ cùng theme/viewport và cùng cấu hình license local ở cả hai phía. Năm vùng workspace × sáu projects có geometry không đổi. Baseline hồi quy tự động dùng trạng thái không key, giữ nguyên watermark/cảnh báo vendor, không mask hoặc sửa cơ chế license.
